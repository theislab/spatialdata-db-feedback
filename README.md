# SpatialData-DB feedback

This repository collects feedback and data reports for [SpatialData-DB](https://spatialdata-db-web.pages.dev/), a catalog of spatial omics datasets that you can load as SpatialData objects. It holds no code. The Python client lives in [spatialdata-db-client](https://github.com/theislab/spatialdata-db-client), and its docs are at [spatialdata-db.readthedocs.io](https://spatialdata-db.readthedocs.io/en/latest/).

SpatialData-DB is in an early alpha, so datasets and features are still being added and things can change.

## How to report something

- **A problem with a dataset**, e.g. wrong metadata, a broken viewer or a missing image: use "Flag a data issue" on the dataset's page, or [open a data problem issue](https://github.com/theislab/spatialdata-db-feedback/issues/new?template=data-problem.yml). Please include the dataset uid or the page link.
- **A dataset you'd like in the catalog**: [suggest a dataset](https://github.com/theislab/spatialdata-db-feedback/issues/new?template=suggest-a-dataset.yml). A link or accession (e.g. a GEO series) and its licence help us most.
- **Anything else**, e.g. a bug in the website or the client, or a question: [open a blank issue](https://github.com/theislab/spatialdata-db-feedback/issues/new).
